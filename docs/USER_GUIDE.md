## 🎮 Mock 服务配置

### 启用/禁用 Mock

在登录页面或任意页面控制台：

```javascript
// 禁用 Mock（使用真实 API）
mockInterceptor.setEnabled(false)

// 启用 Mock
mockInterceptor.setEnabled(true)
```

### 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 延迟 | 300ms | 模拟网络延迟 |
| 错误率 | 2% | 模拟网络错误概率 |

## 🔧 常见问题

### 1. 登录后提示"登录已过期"

**原因**: Mock 模式下 Token 永不过期，此提示说明可能误关了 Mock。

**解决**: 检查 `.env.development` 中 `VUE_APP_MOCK=true`

---

### 2. 数据加载失败

**可能原因**:
- Mock 服务被禁用
- 网络连接问题

**解决**:
```bash
# 检查 Mock 状态
console.log(isMockEnabled())

# 重新启用 Mock
mockInterceptor.setEnabled(true)
```

---

### 3. 上传文件失败

**Mock 模式下**: 文件上传是模拟的，不会真正上传到服务器。

**真实 API 模式**: 检查后端服务是否运行。

---

### 4. 图表不显示

**解决**:
1. 检查浏览器控制台是否有错误
2. 清除缓存重新加载
3. 确保 ECharts 正常加载

## 🎓 拉曼光谱基础知识

### 什么是拉曼光谱？

拉曼光谱（Raman Spectrum）是一种分子振动光谱，通过分析散射光的频率变化来确定物质的分子结构。

### 主要特征峰

| 峰位 (cm⁻¹) | 归属 |
|-------------|------|
| ~500 | Si-Si 键振动 |
| ~1000 | C-C 伸缩振动 |
| ~1332 | sp³ 碳（金刚石）|
| ~1580 | sp² 碳（石墨 G 峰）|
| ~2700 | 2D 峰（石墨烯特征）|
